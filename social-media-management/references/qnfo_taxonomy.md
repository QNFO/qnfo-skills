## Social Discovery Protocol

1. **Bluesky**: search `https://bsky.app/search?q=<keyword>` — centralized search.
2. **Mastodon**: `GET /api/v2/search?q=<keyword>&resolve=true` on `mathstodon.xyz`, `fediscience.org`, `qoto.org` — instance-scoped; run per-instance.
3. **X/Twitter**: search via x.com (manual) or DataWhisker/x-mcp-server (26 tools) for reading; follows are manual (API removed).
4. **GitHub users**: star-target org owners from Part 5 patterns often mirror social handles.
5. **Verify before adding**: Bluesky → `verify_bsky_handles.py` (unauthenticated resolveHandle). Mastodon → `mastodon_follow.py follow` dry resolution. Set `verified: true` only after live confirmation.
